Shapley-like values are a principled tool for data valuation, but exact computation and static stratified estimators can require prohibitively many samples.

ASSS introduces two adaptive strategies: one stratifies after sampling, while the other stratifies before sampling. Both remain unbiased and offer different trade-offs between sample efficiency and memory usage.

This work is published in **Proceedings of the ACM on Management of Data (PACMMOD), 2026**.
